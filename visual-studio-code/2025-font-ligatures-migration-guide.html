Common Mistakes with font ligatures (and Fixes)

Conclusion

FAQ

Can I use font ligatures in an existing project, or only in new ones?

Both. Retrofitting font ligatures into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day one.

What should I learn after font ligatures?
