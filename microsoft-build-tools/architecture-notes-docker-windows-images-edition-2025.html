Use a response/config file with exact component IDs and channel manifests, or bake a versioned image. Combine with global.json for the .NET SDK and lock files for NuGet restore.

Does Docker windows images work on Linux, macOS, and Windows?

Yes. Cross-platform support is a core expectation in 2025, and the workflow is nearly identical across operating systems. The few differences that remain are documented in the official setup guides.
