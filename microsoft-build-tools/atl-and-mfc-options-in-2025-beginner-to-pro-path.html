Getting Started with ATL and MFC options

Before changing anything, take five minutes to write down what bothers you about the current setup. Is it build speed? Debugging? Deployment? Targeted fixes to ATL and MFC options stick better than wholesale rewrites driven by curiosity.

FAQ

Does ATL and MFC options work on Linux, macOS, and Windows?

Yes. Cross-platform support is a core expectation in 2025, and the workflow is nearly identical across operating systems. The few differences that remain are documented in the official setup guides.

Can I use ATL and MFC options in an existing project, or only in new ones?

Both. Retrofitting ATL and MFC options into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day one.
