Common Mistakes with offline layout installs (and Fixes)

Most offline layout installs problems are not exotic — they are the same handful of mistakes repeated across teams. Catching these early is the cheapest quality improvement available, and none of the fixes require deep expertise.

  • Copy-pasting configuration from an old project without understanding what each block does — audit every imported setting once
