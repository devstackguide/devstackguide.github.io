FAQ

What is the difference between the .NET SDK and the runtime?

The SDK includes the compiler, build tools, and templates used to develop apps; the runtime is what executes a compiled app. Build machines need the SDK, servers often only need the runtime.

Can I use support lifecycle dates in an existing project, or only in new ones?

Both. Retrofitting support lifecycle dates into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day one.
