Can I use string interpolation in MSBuild in an existing project, or only in new ones?

Both. Retrofitting string interpolation in MSBuild into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day.

What is the difference between a property and an item?

Properties are single name-value strings used for configuration; items are typed lists (Compile, PackageReference, Content) that carry per-entry metadata and accumulate through Include/Remove/Update.
