FAQ

Can I use conditional compilation symbols in an existing project, or only in new ones?

Both. Retrofitting conditional compilation symbols into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day.

How do I find out why a property has its value?

Run msbuild /pp:preprocessed.xml to see all imports flattened, or capture a binary log with -bl and open it in the MSBuild Structured Log Viewer to trace each property's origin.
