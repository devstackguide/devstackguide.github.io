FAQ

Where should shared build settings live?

Directory.Build.props for evaluation-time properties and Directory.Build.targets for execution-time customization, at the repository root — MSBuild imports them automatically for every project beneath.

Can I use depends on targets in an existing project, or only in new ones?

Both. Retrofitting depends on targets into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day one.
