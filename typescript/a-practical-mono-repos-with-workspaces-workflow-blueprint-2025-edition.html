Why does TypeScript erase types at runtime?

It compiles to plain JavaScript, so types exist only at compile time. For runtime guarantees, pair TypeScript with validators like Zod that infer static types from schemas.

Can I use mono repos with workspaces in an existing project, or only in new ones?

Both. Retrofitting mono repos with workspaces into an existing project is common — introduce it incrementally, module by module, rather than in one sweeping change. New projects should simply start with it enabled from day one.
